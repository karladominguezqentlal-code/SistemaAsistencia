# Sistema de Asistencia

Programa de consola en Java para consultar la asistencia de 20 alumnos.

Cada alumno tiene uno de estos estados:

- `P`: presente
- `F`: falta
- `R`: retardo

Los datos se guardan en el archivo `lista.json`.

## Opciones del menú

1. Ver el número de faltas.
2. Ver el número de retardos.
3. Ver el porcentaje de asistencia.
4. Ver los nombres de los alumnos con falta.
5. Salir.

Después de cada consulta, el resultado se muestra durante 5 segundos y el programa vuelve al menú principal.

## Cómo usarlo

Abre una terminal dentro de la carpeta del proyecto y ejecuta:

```powershell
javac *.java
java Main
```
